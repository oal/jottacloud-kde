KDE Plasma 6 widget · MPL-2.0

Your Jottacloud sync in KDE, at a glance.

On Linux, Jottacloud ships as a command-line client rather than a desktop app. This widget brings jotta-cli into your KDE Plasma 6 panel: sync state, storage, transfers, read-only backups, and recent activity — no tokens, no private API.

Features

Everything you need to keep an eye on sync

The widget uses the same documented CLI commands you already run, and loads detail only when you open a section.

Made for the panel

Compact by default: show the logo alone, the logo with usage, or a full size and sync summary. Transfer arrows appear only while something is moving.

Storage at a glance

Used and capacity with a usage bar in the dashboard, in the binary units the CLI reports. Finite accounts show a clear percentage.

Sync and transfers

Sync root, current state, local and remote file counts, progress, plus current and recent uploads and downloads — fetched only when you look.

Read-only backups

Every configured backup folder with its status. The widget never edits backup definitions and has no destructive controls.

Activity and errors

Recent sync log entries and the last successful update, with one deduplicated notification when the CLI or sync reports a real problem.

Fits Breeze, speaks Norwegian

Follows your Plasma color scheme, stays usable in narrow panels, and ships in English and Norwegian Bokmål.

Screenshots

See it in your panel

The compact view lives in the panel, the dashboard opens on the desktop, and everything in between is configurable.

Install

From clone to panel in a minute

The widget installs for the current user. No sudo, no background service, no second daemon.

Before you start

  • Plasma 6 with kpackagetool6
  • A logged-in jotta-cli
  • A running jottad daemon
  • Node.js 18+ only for the tests

  1. Clone the repository

    git clone https://github.com/oal/jottacloud-kde.git

  2. Check your environment

    Verifies the Plasma tools and that jotta-cli status --json actually works.

    ./tools/check-environment.sh

  3. Install for your user

    Installs the widget and registers the icon, then add Jottacloud status from right-click panel → Add Widgets.

    ./tools/install.sh

Restart Plasma only after changing metadata.json: ./tools/install.sh --restart. If the CLI is missing or fails, the widget shows an offline state and keeps the last good snapshot.

install — konsole 
$ git clone https://github.com/oal/jottacloud-kde.git
$ cd jottacloud-kde
$ ./tools/check-environment.sh
ok      kpackagetool6 -> /usr/bin/kpackagetool6
ok      plasmawindowed -> /usr/bin/plasmawindowed
ok      qmllint -> /usr/bin/qmllint
ok      node -> /usr/bin/node
ok      CLI -> /usr/bin/jotta-cli
$ ./tools/install.sh
==> installed to /home/you/.local/share/plasma/plasmoids/io.github.oal.jottacloud-kde
==> Add it from: right-click the panel -> Add Widgets -> "Jottacloud status"

More tools

  • ./tools/package.sh builds a distributable .plasmoid
  • ./tools/install.sh --remove uninstalls the widget
  • node --test tests/*.test.mjs runs the pure-logic tests

Configure

Settings that stay out of the way

A short configuration page, mirroring your panel habits: sane defaults, nothing hidden that changes your account.

CLI executable
Defaults to jotta-cli resolved from Plasma's environment. Point it at an absolute path or a non-interactive container wrapper when needed.
Refresh every
30 seconds by default. Polls are serialized, and detail sections load on demand.
Panel storage
Logo only, logo + percentage, or percentage + size + sync status, depending on your panel.
Panel transfers
Show upload and download indicators only while transfers are active.
Account section
Hide account and device information from the dashboard if you don't need it.
Recent entries
How many activity and error rows to keep in view — five by default.
Error notifications
One notification per problem, deduplicated. Normal upload and download progress never notifies.

Safe by design

  • Only documented commands: status, list, log, and syncpaused
  • Never stores or asks for credentials or tokens
  • Never resets, moves, sets up, deletes, archives, or logs out
  • No private API, no daemon restarts, no second daemon
  • Backups and backup folders stay read-only

FAQ

Questions, answered

Do I need the official jotta-cli installed?
Yes. The widget reads the installed jotta-cli and its jottad daemon; it does not authenticate on its own or replace the official client. Log in once with the CLI, then add the widget.
Does Jottacloud have a native Linux or KDE app?
On Linux, Jottacloud provides a command-line client rather than a desktop GUI. This widget is an unofficial companion that surfaces that CLI's status in your KDE Plasma panel — it does not replace the official client or the daemon.
Does it work with a containerized CLI?
Yes, if you have a non-interactive wrapper that works from Plasma's environment. Set it as the CLI executable in the widget settings, and verify it first with jotta-cli status --json.
Can it touch or delete my files?
No. It only reads status, transfer lists, and logs, and it toggles one documented setting for pause and resume. It never runs reset, move, setup, delete, archive, logout, or backup-removal commands.
Will pausing stop my backups?
No. Pause and resume only change the sync syncpaused state. Backup folders keep running and are displayed read-only.
Where are my credentials stored?
Only in your existing jotta-cli/jottad installation. The widget never asks for a token, never stores one, and never talks to Jottacloud's private API.
Which Plasma versions are supported?
Plasma 6 only. The package targets the Plasma 6 declarative applet API and is not available for Plasma 5.
How do I update or uninstall it?
Re-run ./tools/install.sh to upgrade, or ./tools/install.sh --remove to uninstall. Restart plasmashell after metadata changes with ./tools/install.sh --restart.
Is this an official Jottacloud app?
No. It is an unofficial community project, not affiliated with, endorsed by, or supported by Jottacloud AS or KDE e.V. It only uses documented CLI commands, and the official client remains in charge of your account.
